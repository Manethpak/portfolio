Cambodia's location data is fragmented -- different spellings, no standardization, scattered across systems. This project provides a single source of truth: 16,457 administrative units (25 provinces, 210 districts, 1,652 communes, 14,570 villages) with bilingual Khmer/English names and hierarchical codes.

## What It Provides

- **REST API** with full-text search in both Khmer and English, autocomplete, and code-based lookups.
- **Downloadable datasets** in JSON and Excel formats for offline use.
- **Hierarchical administrative codes** that replace fragmented multi-column storage with a single standardized code.

## Use Cases

Research and analytics, address forms and location pickers, data integration across government and business systems, and address validation against authoritative administrative divisions.

## Data Sources

Sourced from Open Development Cambodia and UNOCHA via HDX, validated against the NCDD Gazetteer. Data is licensed under ODbL (Open Database License). Currently at 7 GitHub stars.
